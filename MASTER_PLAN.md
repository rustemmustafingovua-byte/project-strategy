# Portfolio Strategy — Rustem Mustafin

## Общая стратегия

Мы строим **Web3 + AI продуктовый портфель** с фокусом на:
1. **Lumen Chain** — ядро экосистемы (блокчейн + AMM + keeper)
2. **Perps Funding Pulse** — монетизация через x402 и данные
3. **Agent X402** — инфраструктура для платных AI-запросов
4. **Wallet Hygiene** — безопасность и compliance
5. **BetterDriver** — мобильное приложение (Flutter)
6. **Armada QR Network** — инструменты для бизнеса
7. **MCP Proxy** — открытый инструмент для разработчиков

## Философия

- **Open Core**: базовый функционал открыт, продвинутый — платный
- **API-first**: все сервисы exposing API для интеграций
- **Community-driven**: рефералы, открытые Issues, Discord
- **Data moat**: каждое приложение генерирует данные — мы их монетизируем

## Приоритеты

1. **Lumen Chain** — готов к launch, нужно community + marketing
2. **Perps Funding Pulse** — уже имеет users, нужно масштабирование
3. **Agent X402** — infrastructure play, партнёрства с AI-компаниями
4. **BetterDriver** — готова APK, нужно publish + UA
5. **Остальные** — поддержка, minor features

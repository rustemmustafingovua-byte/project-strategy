# Discord-сервер: Lumen Chain Community

## Название сервера
**Lumen Chain Community**

## Роли

| Роль | Цвет | Позиция | Права |
|------|------|---------|-------|
| Admin | Красный | 1 | Полный доступ, управление сервером |
| Mod | Оранжевый | 2 | Модерация, кик/бан, управление каналами |
| Dev | Синий | 3 | Управление #dev-talk, #bounties, #bug-reports |
| Community | Зелёный | 4 | Доступ к #events, #giveaways, помощь новичкам |
| Holder | Фиолетовый | 5 | Доступ к закрытым каналам (при наличии) |
| Bot | Серый | 6 | Только для ботов (Carl-bot, MEE6, TicketTool) |

## Категории и каналы

### 📢 INFORMATION
- `#announcements` — важные объявления проекта, обновления, релизы
- `#rules` — правила сервера (обязательны к прочтению)
- `#roadmap` — дорожная карта Lumen Chain, этапы развития
- `#faq` — часто задаваемые вопросы и ответы

### 💬 GENERAL
- `#general` — свободное общение на любые темы
- `#introductions` — представление newcomers, расскажи о себе
- `#showcase` — демонстрация проектов, достижений, артов
- `#feedback` — предложения по улучшению сервера и проекта

### ⛓️ LUMEN CHAIN
- `#support` — техподдержка, проблемы с кошельком/нодой
- `#minning` — майнинг, пулы, хэшрейт, оборудование
- `#wallet` — кошельки, адреса, транзакции, стейкинг
- `#governance` — голосования, предложения по изменениям в сети

### 📈 TRADING
- `#price-talk` — обсуждение цены LMN, аналитика, прогнозы
- `#market-making` — ликвидность, AMM, стратегии торговли
- `#dex-listings` — листинги на биржах, пары, объёмы

### 🛠️ DEVELOPMENT
- `#dev-talk` — общение разработчиков, архитектура, код
- `#bounties` — баунти, задачи, награды за разработку
- `#bug-reports` — баги, ошибки, issue tracker

### 🎉 COMMUNITY
- `#memes` — мемы, развлечения, хайп
- `#events` — амбассадорские мероприятия, конкурсы, эфиры
- `#giveaways` — раздачи, конкурсы, призы

## Правила автоматической модерации

### Автомод (carl-bot / mee6 / ticketool)

1. **Спам** — более 5 сообщений за 10 секунд → mute 5 минут
2. **Массовые упоминания** — более 3 упоминаний за одно сообщение → delete + warn
3. **Оскорбления** — словоизбытие из списка запрещённых слов → delete + mute 10 минут
4. **Ссылки на скам/фишинг** — чёрный список доменов → delete + ban (по решению модератора)
5. **Крайние символы** — более 10 эмодзи/капса подряд → delete + warn
6. **Реклама без разрешения** — любые внешние ссылки от не-модераторов → delete + warn
7. **Флуд в #announcements** — дублирование сообщений → mute 30 минут
8. **Неадекватный контент** — NSFW/политика/религия → delete + mute 1 час

### Порог варнов
- 3 варна → mute 24 часа
- 5 варнов → kick
- 7 варнов → ban

## Инструкция по ручной настройке (copy-paste)

### Создание ролей
1. Server Settings → Roles → Create Role
2. Создай по очереди: Admin, Mod, Dev, Community, Holder, Bot
3. Установи цвета и позиции согласно таблице выше

### Создание категорий и каналов
1. Server Settings → Channels → Create Category
2. Для каждой категории создай текстовые каналы с указанными названиями
3. Настрой права доступа:
   - INFORMATION: все могут читать, писать только Admin/Mod
   - GENERAL: все могут читать и писать
   - LUMEN CHAIN: все читать, писать все
   - TRADING: все читать, писать все
   - DEVELOPMENT: все читать, писать Dev+ (при необходимости)
   - COMMUNITY: все читать и писать

### Автомод
1. Добавь Carl-bot: https://carl.gg/invite
2. Автомод → Rules → создай правила из списка выше
3. Настрой mute/ban действия
4. TicketTool для тикетов поддержки: https://tickettool.xyz/invite

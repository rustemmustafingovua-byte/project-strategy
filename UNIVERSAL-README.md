# Universal Ecosystem — One-Click Setup

## Быстрый старт

```bash
# 1. Установка всех проектов
bash /tmp/universal/install-all.sh

# 2. Запуск всех сервисов
bash /tmp/universal/start-all.sh

# 3. Проверка статуса
bash /tmp/universal/status.sh

# 4. Запуск всех тестов
bash /tmp/universal/test-all.sh
```

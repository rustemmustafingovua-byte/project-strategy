## Title: Show HN: Lumen Chain – blockchain in TypeScript with native AMM

URL: https://github.com/rustemmustafingovua-byte/lumen-chain

Lumen Chain is a Layer-1 blockchain written entirely in TypeScript, targeting IoT and edge devices. Key points:

- PoA consensus with ~2s block time
- libp2p networking
- 500+ TPS on 7-node Raspberry Pi 4 testnet
- Custom bytecode VM (not EVM) with Ethereum JSON-RPC compatibility
- 100% open source

I chose TypeScript because its static typing catches consensus bugs early, and the npm ecosystem makes on-chain/off-chain code sharing trivial. Curious if others have experience with TS for systems programming at this scale.

Happy to answer questions about the VM, consensus, or roadmap.

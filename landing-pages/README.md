# Landing Pages

Zero-budget набор независимых HTML-страниц. Каждая страница — один файл, без внешних зависимостей.

## Развёртывание на GitHub Pages (бесплатно)

1. Создайте публичный репозиторий, например `landing-pages`.
2. Загрузите файлы в ветку `main`.
3. В репозитории откройте Settings → Pages.
4. Источник: ветка `main`, папка `/root`.
5. Сохраните. Сайт появится по адресу:
   `https://<username>.github.io/landing-pages/`

## Локальный просмотр

Откройте `index.html` в браузере двойным кликом. Должны работать все ссылки между страницами.

## Структура

- `index.html` — каталог проектов
- `lumen-chain.html`
- `perps-funding-pulse.html`
- `agent-x402.html`
- `wallet-hygiene.html`
- `betterdriver.html`

## Изменение

Все страницы используют одну цветовую схему и структуру. Можно редактировать вручную или скопировать `index.html` как шаблон для нового проекта.

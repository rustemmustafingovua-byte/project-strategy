# BetterDriver — Roadmap & Go-to-Market

## Vision
Сделать лучшим навигатором для незрячих и слабовидящих водителей.

## Product Roadmap

### Q4 2026 (Current)
- [x] Release APK (74MB)
- [x] Basic navigation
- [x] Voice guidance
- [x] Route planning

### Q1 2027
- [ ] Google Play launch
- [ ] 1000 installs
- [ ] App Store (iOS) launch
- [ ] Community feedback integration
- [ ] Accessibility audit

### Q2 2027
- [ ] 10k installs
- [ ] Premium features (offline maps, advanced routing)
- [ ] Fleet management for organizations

## Marketing Plan
1. **Accessibility community** — RNIB, AFB, local blind associations
2. **Reddit** — r/blind, r/accessibility
3. **Twitter** — #Accessibility #a11y
4. **YouTube** — demo videos, testimonials
5. **Press** — tech blogs covering accessibility

## Revenue Model
- Free: basic navigation with ads
- Premium: $4.99/mo (no ads, offline maps)
- Enterprise: fleet management $99/mo
- Donations: Patreon

**Target MRR: $5k by Q2 2027**

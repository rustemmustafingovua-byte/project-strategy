# x402: протокол монетизации AI API

## Проблема: AI-агенты не платят

Современные LLM-агенты могут выполнять HTTP-запросы, но они не имеют кошелька. Конечные точки (endpoints) не знают, кто обратился, и не могут запросить оплату. Результат?

- API-провайдеры несут расходы, не получая дохода
- Разработчики боятся открывать свои модели
- Мониторинг использования — вручную

## Решение: HTTP 402 + блокчейн

x402 — это простой протокол: сервер отвечает **402 Payment Required**, указывая:
- Сумму в USDC
- Адрес кошелька
- Хеш задачи

Клиент (AI-агент) подписывает транзакцию, повторяет запрос с заголовком `X-Payment-Proof`. Сервер проверяет оплату — и возвращает результат.

Никаких интеграций. Никаких SDK. Только стандартный HTTP.

## Как это работает: 4 шага

1. **Запрос** — агент вызывает `/v1/complete`
2. **402** — сервер отвечает: «0.01 USDC, адрес `0xABC...`, хеш `abc123`»
3. **Оплата** — агент отправляет транзакцию в mempool
4. **Подтверждение** — повторный запрос с `X-Payment-Proof`

Всё. Запрос выполнен, провайдер получил деньги, агент получил ответ.

## Зачем это AI-индустрии

Сейчас разработчики размещают API в тени, используют ключи, лимиты, сложный биллинг. x402 убирает посредников:

- **Для провайдеров**: мгновенная оплата, прозрачный учёт, анти-DoS за счёт платы за запрос
- **Для разработчиков**: открытые модели, которые можно вызывать из любого агента
- **Для пользователей**: прозрачные тарифы, оплата за фактическое использование

## Технические детали

- Поддержка EVM-совместимых сетей (Base, Ethereum)
- Стандартный заголовок `X-Payment-Proof`
- Формат JSON для тела 402-ответа
- Открытая спецификация

Мы уже интегрировали x402 в **Agent X402** — демо, где автономный агент платит за API-вызовы сам.

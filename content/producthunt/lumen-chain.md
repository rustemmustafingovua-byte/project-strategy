# Lumen Chain — Product Hunt Launch Kit

## Tagline
Build blockchain apps in TypeScript. No Rust, no Go, just familiar tooling.

## Description
Lumen Chain is an open-source Layer-1 blockchain built entirely in TypeScript. Designed for IoT and edge devices, it brings the safety of static typing and the speed of the JS ecosystem to blockchain development.

**Key features:**
- PoA consensus (~2s block time, 500+ TPS on Raspberry Pi 4)
- Ethereum-compatible JSON-RPC API
- Custom smart contract VM with safe memory semantics
- TypeScript SDK for deploying contracts in 5 minutes
- Full block explorer built with React + TypeScript

No more context-switching between languages. If you can write TypeScript, you can build on Lumen Chain.

## Target audience
- TypeScript/JavaScript developers curious about blockchain
- IoT and edge computing teams needing lightweight nodes
- Web3 founders tired of EVM limitations
- Open-source contributors looking for auditable consensus code

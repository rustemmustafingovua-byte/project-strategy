1/ AI-агенты могут делать запросы к API, но они не умеют платить. Конечные точки не знают, кто обратился, и не могут запросить оплату.

Проблема?

2/ Провайдеры API несут расходы, не получая дохода. Разработчики боятся открывать модели, используют ключи, лимиты, сложный биллинг.

3/ x402 решает это просто: сервер отвечает HTTP 402 Payment Required с суммой в USDC и хешем задачи.

4/ Агент подписывает транзакцию, повторяет запрос с заголовком X-Payment-Proof. Сервер проверяет оплату — возвращает результат.

Никаких SDK. Только стандартный HTTP.

5/ 4 шага:
1. Запрос → /v1/complete
2. 402 → "0.01 USDC, 0xABC..., хеш abc123"
3. Оплата → транзакция в mempool
4. Подтверждение → повторный запрос с proof

6/ Поддерживаются EVM-сети: Base, Ethereum. Стандартный заголовк, открытая спецификация.

7/ Мы уже интегрировали x402 в Agent X402 — автономный агент, который платит за API-вызовы сам.

8/ Документация и примеры на github.com/agent-x402/x402

AI должен платить за ресурсы так же, как и люди. x402 делает это возможным.

🧵 1/ x402 — это протокол оплаты для API, который убивает абонентские модели.

Каждый запрос стоит столько, сколько он реально стоит. Без подписки. Без карт. Без реестров.

Вот как это работает.

2/ Проблема, которую решает x402:

AI-агенты автономно потребляют API. Но как они платят? Кредитная карта агента — это плохая идея. Подписка тоже не очень.

Решение: **микро-платежи за каждый запрос**, прозрачные и без участия человека.

3/ Как это работает технически:

- Сервер возвращает `402 Payment Required` с деталями: токен, сумма, nonce
- Клиент подписывает транзакцию и добавляет заголовок `PAYMENT: usdc 0.002 <signature>`
- Сервер проверяет подпись и баланс
- Если ок — возвращает ответ

4/ Безопасность:

- Подпись привязана к методу, URL, телу и времени
- Nonce предотвращает replay-атаки
- Ограничение по сумме

5/ Я создал Agent X402 — полноценный пример AI-агента, который платит за API автономно.

Три строки кода на клиенте. Десять на сервере. Никаких OAuth, никаких вебхуков.

6/ x402 — это не замена Stripe. Это протокол для машино-машинных платежей.

Через пару лет "платить за API" будет означать именно x402, а не "подписка за $49/мес".
